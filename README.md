TOKIPICK

TOKIPICK es una aplicación de moda que combina recomendaciones personalizadas, un placard digital y comparación de productos para facilitar decisiones de compra según el estilo y presupuesto del usuario.

Objetivos
- Personalizar el descubrimiento de prendas mediante Swipe.
- Organizar prendas en un placard digital.
- Crear outfits con ropa propia y recomendaciones.
- Facilitar la comparación de precios, materiales y calidad.
- Reducir compras innecesarias y ahorrar tiempo y dinero.

Funcionalidades
- Registro e inicio de sesión.
- Exploración de prendas mediante Swipe.
- Recomendaciones de productos.
- Placard digital (Closet).
- Creación de outfits.
- Detalles y comparación de productos.
- Carrito de compras.
- Perfil y sección de ayuda.

Fortalezas
- Integra organización del placard y exploración de ropa nueva.
- Promueve compras más informadas.
- Ofrece una experiencia visual e interactiva.
- Busca reducir la saturación visual y simplificar la navegación.

Debilidades
- La utilidad de las recomendaciones depende de las preferencias registradas.
- Cargar y organizar el placard puede requerir tiempo.
- La precisión de las comparaciones depende de la información disponible de cada producto.

Limitaciones
- La comparación depende de datos suficientes y actualizados.
- La integración con catálogos, pagos y pedidos requiere servicios externos para operar plenamente.
- La compatibilidad con otros idiomas, el uso offline y los perfiles sociales se consideran mejoras futuras.

Público objetivo
Personas que compran ropa online y buscan optimizar su presupuesto, combinar prendas y elegir productos con una mejor relación precio-calidad.

Tecnologías
Interfaz web desarrollada con HTML, CSS y JavaScript.
